# Requisitos del sistema - Mood-Up

## 1. Introducción

Los requisitos del sistema permiten definir las funcionalidades y características que debe cumplir la aplicación Mood-Up. Estos se dividen en requisitos funcionales, relacionados con las acciones y servicios que ofrece el sistema, y requisitos no funcionales, relacionados con las características de calidad y comportamiento de la aplicación.

---

## 2. Requisitos funcionales

### RF01 - Registro e inicio de sesión

El sistema debe permitir a los usuarios registrarse e iniciar sesión para acceder a las funcionalidades de Mood-Up.

### RF02 - Selección del estado emocional

El sistema debe permitir al usuario seleccionar o indicar su estado emocional para personalizar la experiencia y el contenido ofrecido.

### RF03 - Retos personalizados

El sistema debe proporcionar retos o actividades personalizados de acuerdo con el estado emocional identificado o seleccionado por el usuario.

### RF04 - Recomendaciones de películas y series

El sistema debe proporcionar recomendaciones de películas y series relacionadas con el estado emocional del usuario.

### RF05 - Tema claro y oscuro

El sistema debe permitir al usuario seleccionar entre un tema claro y un tema oscuro para la interfaz de la aplicación.

### RF06 - Asistente de identificación emocional

El sistema debe contar con un asistente que permita apoyar al usuario en la identificación de su estado emocional.

### RF07 - Frases motivacionales

El sistema debe proporcionar frases motivacionales de acuerdo con la experiencia y el estado emocional del usuario.

### RF08 - Visualización de tráileres

El sistema debe permitir la visualización de tráileres relacionados con el contenido audiovisual recomendado.

### RF09 - Calificación del contenido

El sistema debe permitir al usuario calificar el contenido audiovisual disponible en la aplicación.

---

## 3. Requisitos no funcionales

### RNF01 - Usabilidad

La aplicación debe ofrecer una interfaz comprensible y fácil de utilizar, permitiendo al usuario interactuar con las funcionalidades de manera sencilla.

### RNF02 - Compatibilidad

El sistema debe ser compatible con los entornos y dispositivos definidos para la aplicación, permitiendo su correcto funcionamiento.

### RNF03 - Rendimiento

El sistema debe responder de manera adecuada a las solicitudes realizadas por los usuarios, manteniendo un rendimiento apropiado durante su funcionamiento.

### RNF04 - Seguridad

El sistema debe proteger la información de los usuarios y controlar el acceso a las funcionalidades mediante mecanismos de autenticación y seguridad.

### RNF05 - Mantenibilidad

El sistema debe contar con una estructura que facilite su mantenimiento, actualización y modificación.

### RNF06 - Disponibilidad

Las funcionalidades del sistema deben estar disponibles para los usuarios cuando sean requeridas, de acuerdo con las condiciones de funcionamiento establecidas.

### RNF07 - Consistencia

La información y el comportamiento del sistema deben mantenerse consistentes entre sus diferentes componentes y funcionalidades.

### RNF08 - Escalabilidad

El sistema debe contar con una estructura que permita incorporar nuevas funcionalidades y soportar el crecimiento del proyecto.
