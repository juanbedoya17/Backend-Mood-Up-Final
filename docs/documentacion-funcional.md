# Documentación funcional – MoodUp

La documentación funcional describe las principales funcionalidades de MoodUp desde la perspectiva del usuario, indicando el propósito de cada función, el flujo principal de interacción, el resultado esperado y las condiciones necesarias para su funcionamiento.

## 1. Registro e inicio de sesión

### Descripción

MoodUp permite al usuario registrarse e iniciar sesión para acceder a las funcionalidades personalizadas de la aplicación.

**Actor:** Usuario.

### Flujo principal

1. El usuario ingresa a la aplicación.
2. Selecciona la opción de registro o inicio de sesión.
3. En caso de registro, proporciona la información solicitada y crea su cuenta.
4. En caso de inicio de sesión, ingresa sus credenciales.
5. El sistema valida la información.
6. Si los datos son correctos, el usuario accede a la aplicación.

### Resultado esperado

El usuario puede ingresar a MoodUp y acceder a sus funcionalidades personalizadas.

### Condiciones

El usuario debe proporcionar información válida para completar el registro o iniciar sesión.

---

## 2. Selección e identificación del estado emocional

### Descripción

MoodUp permite al usuario seleccionar directamente su estado emocional o utilizar un asistente de preguntas cuando no sabe cómo se siente.

**Actor:** Usuario.

### Flujo principal

1. El usuario accede a la sección de estado emocional.
2. Puede seleccionar directamente una de las emociones disponibles.
3. Si no identifica su emoción, puede acceder a la opción de asistencia.
4. El sistema presenta preguntas relacionadas con aspectos como energía, estado corporal y estado mental.
5. El usuario responde las preguntas.
6. El sistema sugiere una emoción de acuerdo con las respuestas proporcionadas.
7. El estado emocional seleccionado o identificado queda registrado.

### Resultado esperado

El usuario obtiene un estado emocional que puede utilizarse para acceder a contenido y actividades relacionadas.

### Condiciones

El usuario debe seleccionar una emoción o completar el asistente para continuar con las recomendaciones.

---

## 3. Recomendaciones de películas y series

### Descripción

La aplicación proporciona recomendaciones de contenido audiovisual relacionadas con el estado emocional registrado por el usuario.

**Actor:** Usuario.

### Flujo principal

1. El usuario registra o identifica su estado emocional.
2. Selecciona la opción de películas o series.
3. El sistema consulta el contenido asociado con la emoción seleccionada.
4. Se muestran las recomendaciones disponibles.
5. El usuario puede seleccionar una recomendación para consultar su información.

### Resultado esperado

El usuario obtiene contenido audiovisual relacionado con su estado emocional.

### Condiciones

Debe existir un estado emocional seleccionado para generar las recomendaciones correspondientes.

---

## 4. Retos personalizados

### Descripción

MoodUp ofrece retos relacionados con el estado emocional del usuario, con el propósito de incentivar actividades orientadas a su bienestar.

**Actor:** Usuario.

### Flujo principal

1. El usuario registra su estado emocional.
2. Accede a la sección de retos.
3. El sistema muestra retos relacionados con la emoción registrada.
4. Realiza la actividad propuesta.
5. Puede marcar el reto como completado.

### Resultado esperado

El usuario puede realizar y registrar los retos disponibles.

### Condiciones

Los retos dependen del estado emocional registrado y deben estar disponibles en el sistema.

---

## 5. Frases motivacionales

### Descripción

El sistema presenta frases motivacionales relacionadas con el estado emocional del usuario.

**Actor:** Usuario.

### Flujo principal

1. El usuario registra o selecciona su estado emocional.
2. El sistema identifica la emoción seleccionada.
3. Se muestra una frase motivacional relacionada con dicha emoción.

### Resultado esperado

El usuario recibe un mensaje de apoyo relacionado con su estado emocional.

### Condiciones

Debe existir contenido motivacional asociado al estado emocional seleccionado.

---

## 6. Historial emocional

### Descripción

MoodUp permite al usuario consultar los estados emocionales registrados anteriormente para realizar un seguimiento de sus emociones.

**Actor:** Usuario.

### Flujo principal

1. El usuario registra diferentes estados emocionales en la aplicación.
2. El sistema almacena los registros correspondientes.
3. El usuario accede a la sección de historial.
4. El sistema muestra los estados emocionales registrados anteriormente.
5. El usuario puede consultar la información disponible.

### Resultado esperado

El usuario puede revisar sus registros emocionales anteriores y observar cómo han cambiado sus estados de ánimo.

### Condiciones

El historial depende de que el usuario haya realizado registros emocionales previamente.

---

## 7. Visualización de tráilers

### Descripción

La aplicación permite acceder a los tráilers relacionados con las películas y series recomendadas.

**Actor:** Usuario.

### Flujo principal

1. El usuario consulta una recomendación audiovisual.
2. Selecciona la opción para visualizar el tráiler.
3. El sistema muestra o dirige al recurso correspondiente.
4. El usuario puede visualizar el tráiler antes de decidir si desea consultar o ver el contenido.

### Resultado esperado

El usuario puede conocer mejor el contenido recomendado mediante su tráiler.

### Condiciones

La recomendación debe contar con un tráiler disponible.

---

## 8. Calificación del contenido

### Descripción

MoodUp permite al usuario calificar las recomendaciones recibidas y registrar su valoración.

**Actor:** Usuario.

### Flujo principal

1. El usuario consulta una recomendación.
2. Selecciona la opción de calificación.
3. Ingresa la valoración correspondiente.
4. El sistema registra la calificación.

### Resultado esperado

La valoración del usuario queda registrada para el contenido seleccionado.

### Condiciones

El usuario debe haber accedido previamente a una recomendación disponible para poder realizar la calificación.

---

## 9. Cambio de tema claro/oscuro

### Descripción

MoodUp permite al usuario cambiar entre el modo claro y el modo oscuro de la aplicación para personalizar la apariencia de la interfaz.

**Actor:** Usuario.

### Flujo principal

1. El usuario ingresa a la aplicación.
2. Accede a la opción correspondiente a la configuración o apariencia.
3. Selecciona el modo claro o el modo oscuro.
4. El sistema aplica el tema seleccionado a la interfaz.

### Resultado esperado

La aplicación cambia su apariencia de acuerdo con la preferencia seleccionada por el usuario.

### Condiciones

El usuario debe tener acceso a la opción de cambio de tema dentro de la aplicación.
